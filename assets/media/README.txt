Home page background. Put ONE of these here and it is picked up automatically:

    hero.mp4          a short silent loop (10-20 s, 1920x1080, under about 8 MB)
    hero-poster.jpg   optional still frame shown while the video loads
    hero.gif          used only if there is no hero.mp4 (animated gif or webp, or a still jpg renamed)

With none of these present, the built-in line animation plays instead.
The paths can be changed in content/site.js.
